# Real country profile data

The built-in roster contains the 193 UN member states, the two UN General Assembly non-member observer states, and Kosovo and Taiwan as additional self-governing selections with neutral status notes. It is an offline snapshot, not a live political feed.

- Country names and broad government-system classifications for the 193 UN member states were taken from the Inter-Parliamentary Union (IPU) Parline country API on 24 September 2026. IPU's taxonomy distinguishes presidential, parliamentary, presidential–parliamentary, monarchy, communist, and transitional systems. IPU data is licensed CC BY-NC-SA 4.0; see <https://www.ipu.org/terms-use> and <https://creativecommons.org/licenses/by-nc-sa/4.0/>.
- Population (`SP.POP.TOTL`) and GDP in current US dollars (`NY.GDP.MKTP.CD`) are the latest World Bank observations from 2020–2023 available when collected on 24 September 2026. The World Bank API refresh metadata was 13 July 2026. See <https://api.worldbank.org/v2/country/all/indicator/SP.POP.TOTL> and <https://api.worldbank.org/v2/country/all/indicator/NY.GDP.MKTP.CD>.
- The roster scope follows the UN's 193 member states and two observer states; see <https://www.un.org/en/about-us> and UN Statistics Division M49 at <https://unstats.un.org/unsd/methodology/m49/>. Kosovo and Taiwan are separately identified as additional playable self-governing entities. Their status notes avoid taking a position on recognition.
- Taiwan's 2023 population is from Taiwan's Registration Information System; see <https://www.ris.gov.tw/info-liferay/app/channel/newsEnglishDetail/24010759>. Kosovo's government profile is based on its Constitution; see <https://gzk.rks-gov.net/ActDocumentDetail.aspx?ActID=3702>. The Holy See's government profile is based on its official State Secretariat page; see <https://www.vatican.va/roman_curia/secretariat_state/documents/informazione_generale/sp_ss_scv_info-generale_en.html>.
- Any missing GDP value is shown as unavailable. The game derives a balanced baseline for its simulation from population; those derived military and production capacities are gameplay values, not historical claims.
